# CodexChat 插件说明（0.1.9）

CodexChat 是 VS Code 中的本地 Codex 会话管理插件。按会话记录中的项目路径归类，提供历史浏览、续接、置顶、删除和 Token 统计。

## 安装与入口

在 VS Code 中运行“扩展：从 VSIX 安装”，选择 `codexchat-0.1.9.vsix`，安装后按提示重新加载窗口。点击活动栏的 CodexChat 图标进入项目列表。插件要求 VS Code 1.96.2 或更高版本。

浏览本地历史不需要调用模型；“进入 Codex”“新建会话”“继续会话”需要安装 OpenAI Codex 扩展。官方扩展的历史跳转接口发生变化时，会降级为打开 Codex 并复制会话 ID。

## 项目和会话管理

| 操作 | 使用方式 | 结果 |
| --- | --- | --- |
| 查看项目 | 点击项目名称 | 显示该项目会话 |
| 查看会话 | 点击会话标题 | 在只读详情面板显示消息、使用量和分支信息 |
| 项目置顶 | 点击项目行的图钉 | 按钮立即高亮，项目移到未置顶项之前 |
| 会话置顶 | 点击会话行的图钉 | 按钮立即高亮，会话移到未置顶项之前 |
| 取消置顶 | 再次点击高亮图钉 | 恢复按钮颜色与按更新时间排序的顺序 |
| 永久删除会话 | 点击会话行或详情的删除按钮，确认删除 | 删除该会话本地 JSONL 文件及同 ID 的归档副本，清理置顶；操作不可撤销 |
| 删除项目数据 | 点击项目行删除按钮，核对会话数量后确认 | 删除确认时识别的项目会话（包括隐藏归档），清理项目记录和置顶，保留实际项目文件夹 |

置顶状态保存在 VS Code 的全局扩展状态中，重新加载后保留。删除和置顶会直接刷新列表与统计，不需要滚动页面；操作失败会显示错误，置顶按钮恢复为实际保存的状态。

删除项目后，该项目以后产生的新会话仍会被自动发现。删除范围只包含被识别、路径和会话身份校验通过的本地 JSONL 文件；不会清理 Codex 的数据库、登录配置或云端历史。无法识别的文件不会被当作该项目的会话删除。

## 固定统计栏

项目总览和 Token 统计页底部显示当前索引中全部项目的 Token 总量、项目总数。进入项目后，Token 总量切换为当前项目使用量，项目总数仍为全部项目数量。统计栏在滚动列表之外，始终留在页面底部。

统计来自 JSONL 的使用记录，缺失用量的会话不增加 Token 总量。数字不等于账户余额或账单。仅索引实际存在的项目目录；搜索不改变统计总量，归档显示配置会改变索引和统计范围。

## 设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `codexChat.codexHome` | 空 | 优先使用配置路径，否则使用 `CODEX_HOME`，最后使用当前用户的 `.codex` |
| `codexChat.includeArchivedSessions` | `true` | 在列表和统计中包含归档会话；删除项目始终检查归档文件 |
| `codexChat.enableExperimentalSessionHandoff` | `true` | 尝试在官方扩展中打开指定历史会话，失败时复制会话 ID |
| `codexChat.confirmWorkspaceSwitch` | `true` | 进入另一个项目的 Codex 前确认切换工作区 |

## 0.1.9 更新

- 增加会话永久删除和项目数据删除，均要求模态确认。
- 增加持久化的项目置顶和会话置顶，按钮颜色随状态切换。
- 修复操作等待全量扫描而刷新延迟的问题，防止旧扫描覆盖新状态。
- 增加底部固定统计栏，保留刷新时的滚动位置、搜索光标和中文输入。
- 补齐中英文管理文案和操作失败提示。

源码、文档与安装包同步至 [GitHub 仓库](https://github.com/MathsionYang/CodexChat-)；本次提供 VSIX，不代表已发布到扩展市场。
